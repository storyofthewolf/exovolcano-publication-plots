# exovolcano_publications_plots

## Contains scripts to create bespole plots to feature in an upcoming scientific publication
- Wolf, E.T. et al. (2026) "Simulating volcanic eruptions in diverse planetary context with ExoCAM: Descriptions and baselines" In preparation

## Requires https://github.com/storyofthewolf/exovolcano-analysis 
- CSV files produced by exovolcano-analysis based on time-series .h1. files prodcued by ExoCAM
- CSV's are ingested here to produce various plots for publication

## Note:  This is not meant to be a general and flexible plotting routine.  These plots are bespoke for presentation quality.  See exovolcano-analysis produces numerous scripts by default for quick viewing of the model outputs.
